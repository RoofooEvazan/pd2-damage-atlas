Developer reference

Addresses are virtual addresses in the shipped DLLs: D2Game.dll at 0x6FC20000, D2Common.dll at 0x6FD50000, D2Client.dll at 0x6FAB0000, ProjectDiablo.dll (PD) at 0x10000000. VERIFIED = the real code ran natively in a 32-bit harness that loads the DLL images, and matched on random inputs (plus mutation tests that must fail); READ = read from the disassembly; DATA = PD2's .txt tables.
